A program that writes one short rant about a small everyday annoyance to /output/entry.txt.

Entry (284 characters):

> The office microwave has exactly one job — heat food — and every day at noon it becomes a hostage negotiation between three people reheating fish, one person microwaving popcorn for eight minutes, and me, holding a cold sandwich, wondering when we all agreed lunch is a group project.

## Run it

```sh
python3 main.py
```

## How it works

The program writes a fixed short rant to `/output/entry.txt`. Before writing, it checks the text is non-blank, at most 400 characters, and valid UTF-8, so a bad entry fails loudly instead of being submitted.
